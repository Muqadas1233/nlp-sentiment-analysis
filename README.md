# NLP Sentiment Analysis

An NLP sentiment classification experiment using the UCI Sentiment Labelled Sentences dataset.

## Overview

This project explores how Natural Language Processing (NLP) and Machine Learning can be used to classify text as positive or negative.

## Technologies Used

- Python
- Pandas
- NumPy
- NLTK
- Scikit-learn
- Matplotlib
- Seaborn

## Machine Learning Techniques

- TF-IDF Vectorization
- Logistic Regression
- Multinomial Naive Bayes

## Dataset

The experiment uses the UCI Sentiment Labelled Sentences dataset, containing 3,000 labelled sentences from IMDb, Amazon, and Yelp.

Dataset source:
https://archive.ics.uci.edu/dataset/331/sentiment+labelled+sentences

## Experiment Workflow

Text Data
→ TF-IDF Vectorization
→ Train/Test Split
→ Machine Learning Models
→ Model Evaluation
→ Sentiment Prediction

## Evaluation

The models were compared using accuracy and classification metrics.

A confusion matrix was also used to evaluate the best-performing model.

## Results

The actual experimental results are available in the Jupyter Notebook.

## Learning Outcome

This experiment helped me understand how text can be transformed into numerical features using TF-IDF and then used to train machine learning models for sentiment classification.
